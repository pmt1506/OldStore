OldStore

Tra cứu bundle ID App Store, lấy license và lưu trữ file IPA cho thiết bị iOS đời thấp.

Chế độ Vercel (giới hạn): chỉ tra cứu bundle ID và xác nhận license, mỗi lần thao tác là một request độc lập (không lưu phiên đăng nhập). Không tải/lưu trữ IPA được ở đây vì Vercel không có ổ đĩa bền vững và giới hạn response ~4.5MB. Muốn tải & lưu trữ IPA đầy đủ, hãy tự host bằng Docker — xem README.

Mật khẩu truy cập

1. Tài khoản Apple ID

Mật khẩu và mã 2FA chỉ dùng để xác thực với Apple, không lưu lại trên server.

2. Tra cứu app (link App Store / bundle ID / trackId)

3. Thư viện IPA đã tải
